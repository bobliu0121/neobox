# 音乐中心

NeoBox 内置多平台音乐搜索与播放，不依赖浏览器切换即可完成搜索、试听与歌单管理。

## 功能特性

- **多平台聚合**：网易云、酷狗、QQ 音乐、咪咕、汽水、Spotify 六个来源。
- **匿名试听**：未登录也可搜索和试听；VIP/版权受限曲目会显示标识。
- **播放器视图**：封面渐染、透明彩胶、沉浸、音域回响、现代、通透多种样式。
- **系统媒体控制**：播放信息接入 Windows SMTC，支持系统媒体键与锁屏/音量浮层。
- **桌面歌词与灵动岛**：歌词可独立窗口显示，并与灵动岛状态同步。
- **音频增强**：内置均衡器（EQ）与频谱可视化。

## 使用方式

1. 进入「音乐」页面，选择平台并搜索；
2. 点击歌曲试听，或登录对应平台账号以获取更高音质/完整曲库；
3. 在播放器右下角切换播放器样式；
4. 在设置中配置桌面歌词、全局媒体键与音频输出。

## 本地音乐

「本地导入的歌单」支持三种导入方式：

| 入口 | 行为 |
| --- | --- |
| 本地导入 | 选择一个或多个音频文件，作为零散歌曲 |
| 仅当前文件夹 | 只导入所选文件夹第一层的音频 |
| 含子文件夹 | 递归导入所选文件夹及所有子文件夹中的音频 |

每次按文件夹导入都会在「本地导入的歌单」下生成一个子文件夹条目，显示歌曲数、
导入模式与移除按钮；点击即可只查看该文件夹的歌曲。文件夹列表与歌曲归属保存在
`music-player-settings.json`，重启后仍然保留。

本地音乐列表顶部提供搜索框，可按标题、艺术家、专辑即时过滤。导入的 `.mka` 文件
会先解封装为可播放音频缓存，详见 [MKA 合成与播放](mka.md)。

## 说明

- 各平台登录态、歌单与音量设置保存在本机。
- 汽水音乐的部分签名组件属于第三方专有文件，不随开源仓库分发；缺少时该平台功能会降级。
- 音频通过本地代理播放，不经过 NeoBox 的远程服务器。
