# NeoBox 1.1.0

## 音乐

- 搜索无结果时明确显示「搜索不到」，不再静默空白。
- 修正 VIP / 付费歌曲标注：网易云免费低音质歌曲不再误标 VIP，付费专辑单独标记「付费」。
- MKA 内嵌双行字幕可正确显示为两行（歌词面板与桌面歌词同步修复）。
- 未登录也可点击红心：收藏写入本地并持久化，左侧新增「我的红心」入口，登录后仍会同步各平台云端收藏。
- MKA 文件可直接拖到 `neobox.exe` 上打开，自动导入本地歌库并开始播放。

## 导入与后台任务

- 音乐、壁纸、图片 / 音频 / 视频转换、MKA 组合、设置背景、EQ 预设均支持文件拖入。
- 视频转换与 MKA 组合改为全局后台任务：切换页面不会中断，完成后通过灵动岛提示，返回页面仍可看到结果。
- 壁纸页支持拖入图片直接应用，拖入文件夹按「含子文件夹」导入。

## 其他

- 「设置 → 关于」顶部品牌图连续点击 5 次触发彩蛋，灵动岛显示 `彩蛋 x/5` 进度，第 5 次打开指定视频。
- 注册 `.mka` 文件关联（安装版），便携版可直接把文件拖到 exe 使用。
- 版本号更新至 1.1.0。
