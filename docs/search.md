# 文件搜索

侧边栏「搜索」页提供类似 Everything 的本地文件名即时搜索。索引只在内存中建立，不上传任何文件信息。

## 索引方式

| 场景 | 实现 | 速度 |
| --- | --- | --- |
| NTFS 整盘 | `FSCTL_ENUM_USN_DATA` 直接枚举 MFT | 通常 1~5 秒 / 百万文件 |
| 指定文件夹 | `walkdir` 递归扫描 | 取决于目录大小 |
| 非 NTFS 卷 / USN 不可用 | 自动回退到递归扫描 | 取决于磁盘大小 |

USN 枚举需要管理员权限。NeoBox 默认以管理员身份运行，因此整盘索引会走 MFT；如果打开卷或枚举失败，会自动回退到目录遍历并在日志中记录原因。

索引结构只保存文件名和父子关系，不保存完整路径。查询时按需拼接路径并读取文件元数据（大小、修改时间），因此内存占用较低，输入即搜。

## 使用

1. 首次打开页面时自动为「所有磁盘」建立索引；也可在范围下拉框中选择单个磁盘或「指定目录…」。
2. 输入关键词即可搜索，支持 `Ctrl+F` 聚焦搜索框。
3. 通过「格式」筛选全部、仅文件夹、文档、图片、视频、音频、压缩包、代码、程序，或输入自定义扩展名（逗号分隔）。
4. 双击结果打开文件；`↑` / `↓` 选择、`Enter` 打开、`Ctrl+Enter` 在资源管理器中定位；右键可复制路径。
5. 排序支持名称、修改日期、格式、大小，可切换正序 / 倒序；排序结果会持久化。

修改搜索范围会重建索引；修改格式、隐藏文件、大小写选项只影响查询，不会重建。

## 限制

- 索引保存在进程内，重启 NeoBox 后首次进入搜索页会重新建立。
- 全盘索引覆盖所有本地固定/可移动磁盘；网络驱动器不会被自动索引。
- 最多返回 500 条；总数仍会统计全部匹配项。
- 按“修改日期 / 大小”排序时，需要为候选结果读取文件元数据（最多 4000 条），在机械硬盘或结果极多时可能比按名称排序慢；其余排序只使用内存索引。
- 索引建立期间可以取消；切换范围会自动取消旧任务并开始新任务。
- 文件大小与修改时间在展示结果时读取，若文件在索引后被移动/删除，打开时会提示不存在。
